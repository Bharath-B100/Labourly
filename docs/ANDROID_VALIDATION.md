## Physical phone alternative

1. On your phone, enable Developer options and USB debugging, connect a data-capable USB cable, unlock it, and approve the computer's RSA prompt. No phone reset is needed.
2. Run `adb devices -l`; the phone must show `device`, not `unauthorized` or `offline`. Select its serial explicitly if an emulator is also connected. Install an official OEM USB driver only if needed and approved.
3. Use `adb -s PHONE_SERIAL reverse tcp:8080 tcp:8080` and `adb -s PHONE_SERIAL reverse tcp:8082 tcp:8082`. Start Metro on port 8082 with `EXPO_PUBLIC_API_URL=http://127.0.0.1:8080`. This USB route avoids exposing the backend through the firewall. Build with `-PreactNativeDevServerPort=8082` as above; leave the unrelated host application on 8081 alone.
4. After a compatible APK is built, use `adb -s PHONE_SERIAL install -r mobile/android/app/build/outputs/apk/debug/app-debug.apk`, then launch and run the smoke flow. These steps are instructions, not passed checks.
