# Labourly brand assets

The user's supplied hard-hat Labourly identity supersedes the temporary geometric
L used at the start of L1. The unmodified source collage is `brand-reference.png`.
It is retained for comparison; the collage itself is not displayed in the app.

Active assets:

- `wordmark.png`: horizontal Labourly wordmark and Hire Local. Build Better. tagline.
- `hardhat-mark.png`: transparent hard-hat/folded-L symbol for in-app marks,
  Android adaptive foreground, themed-icon alpha mask and native splash.
- `launcher-white.png`: opaque white launcher/favicon version.

These raster derivatives were prepared with the built-in image-generation tool
from the user-supplied reference. They preserve its design and shading but are
not asserted to be pixel-identical crops or editable vector originals. The source
collage remains unchanged. Commercial trademark/artwork ownership has not been
independently established by this implementation.

Prompt set (intent and constraints):

1. Extract only the top horizontal Labourly logo and exact tagline onto real
   transparency; preserve hard-hat/folded-L geometry, lettering and yellow/charcoal
   shading; remove icon tiles, banners, backgrounds and mockup shadows.
2. Extract only the symbol from the right white icon tile onto a transparent
   square; preserve its shape/shading, no text/tile/shadow, generous adaptive-icon
   padding.
3. Composite the same isolated symbol onto a flat opaque white square launcher
   asset, retaining shape and padding, no text or rounded tile.

Exact tool prompts are preserved in the task transcript. Asset SHA-256 hashes and
pixel/alpha metadata are recorded in `asset-manifest.json`. Expo's existing asset
pipeline generates density-specific launcher resources. No external image URL is
required at runtime. Generated files are copied into the repository.

The interface palette remains #FFCC25, #202326, #FFFFFF and #E5E7EB. The approved
brand image retains the supplied gold/charcoal shading. Existing `mark.svg`,
`icon.png`, `foreground.png` and `monochrome.png` are the superseded L1 drafts;
no active application/config reference uses them.

Native launch resources are generated by `plugins/withLabourlyLaunch.js` during
Expo prebuild. Package IDs and Java namespaces remain unchanged. iOS native
launch acceptance remains pending; this run validates Android.
